
## 📘 **Midterm Examination: Class Event Budget and Proposal** <p align="justify">

<p align="justify">
This midterm examination focuses on planning and organizing a class event by preparing a proposed budget and creating a formal event proposal using digital productivity tools. It involves using Google Sheets to list expenses, organize financial information, and calculate the estimated budget, as well as Google Docs to prepare and present the event proposal. Through this activity, I was able to apply my knowledge of digital tools in planning, budgeting, documentation, and organizing an event.
</p>

## ✨ WHAT HAVE I LEARNED?

<p align="justify">
Through this activity, I learned the importance of proper planning, budgeting, and documentation when organizing an event. I discovered how Google Sheets can help manage expenses, perform calculations, and organize financial information, while Google Docs allows me to create a formal and well-structured proposal. I also realized that using digital tools makes planning more organized, efficient, and accurate.
</p>

**◆ Key Concepts and Skills I Gained**

<p align="justify">
I developed my skills in using Google Sheets for creating budget tables, organizing expenses, performing basic calculations, and determining the total estimated cost of an event. I also improved my document preparation skills through Google Docs by learning how to organize the event details and present information in a formal proposal. Additionally, I gained a better understanding of financial planning, resource management, teamwork, and the importance of organizing information systematically.
</p>

**◆ Challenges I Faced and How I Solved Them**

<p align="justify">
One challenge I encountered was ensuring that all expenses were properly listed and accurately calculated in the budget. I also needed to make sure that the financial information in Google Sheets was consistent with the details presented in the Google Docs proposal. I addressed these challenges by reviewing each expense, checking the calculations, organizing the information carefully, and comparing both documents to ensure accuracy and consistency. This experience taught me the importance of being detail-oriented when handling financial information.
</p>

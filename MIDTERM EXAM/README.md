
# Midterm Exam: Class Event Budget and Proposal

## Project Overview
This project uses Google Sheets and Google Docs to plan a class event. Google Sheets was used to compute the event expenses and total budget, while Google Docs was used to create the formal class event proposal.

## Tools Used
- **Google Sheets:** Lists expenses, calculates subtotals, and computes the total budget using formulas.
- **Google Docs:** Presents the event details, objectives, activities, and final budget.

## Workflow
1. List the event expenses in Google Sheets.
2. Calculate the subtotals and total budget.
3. Create the class event proposal in Google Docs.
4. Transfer the final budget total from Sheets to Docs.

## Learning Outcomes
This activity improved our budgeting, document preparation, and Google Workspace skills.

- Google Sheets: Class Event Budget
- Google Docs: Class Event Proposal
